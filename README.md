# nordik-adventures-pgi
Application de commerce électronique et de gestion des stocks développée  avec React, Django et MySQL.

Progiciel de gestion intégré Nordik Adventures
Développement d’une application Web transactionnelle intégrant la gestion des produits et des stocks, les achats, les ventes, la facturation, les clients et les accès selon les rôles.

Technologies : React.js, React-Redux, React Router, Axios, Django, API JSON et MySQL.
